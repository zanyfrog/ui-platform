# Authoritative Saved Card Selection — snapshot and refusal contract

2026-10-25 increment record. The actual Visual source owner exposes `savedCardTarget`, an immutable reader with `snapshot` and `subscribe(listener): unsubscribe`. `WorkspaceEditorAdapter.savedCardTarget?` is additive/optional; coordinator tabs already carry that editor abstraction. Builder shell and saved-Preview request controller do not consume it in this increment.

## Metadata shape

The discriminated result is either `unavailable` with a refusal reason and `target: null`, or `identified` with reason **RETAINED_SAVED_VERSION_ONLY**. Both include monotonic selection/source generations for this owner instance. Identified means a particular already-authorized saved version known to the editor, not fresh server coherence, current permissions, available Preview or an authorization token.

| Field | Provenance |
| --- | --- |
| `target.source.applicationId` | Original permanent Application id supplied by the existing authorized adapter; routing key is not substituted. |
| `target.source.page` | Original application-owner-qualified Visual Page id and optional original owner revision. Repair locators and package/platform-owned selections do not qualify this narrow implementation. |
| `target.source.committedHash` | Exact retained bundle hash, checked against matching EditingLifecycle.baseline files using the existing SHA-256(JSON.stringify(files)) service contract. No filesystem/backend read occurs. |
| `target.source.nodeId` | Explicit selected candidate resolved uniquely by the hardened shared parser against the retained committed baseline. No label, position, generated default or draft bytes establish membership. |
| `target.implementation.componentId` | Canonical Card id `cmp_platform_5d42b928-83bf-4b18-a4c0-48b06c2efa1`, distinct from the Page/node identity. |
| `target.implementation.packageId/packageVersion/importPath/exportName` | Unique retained installed package entry agreeing with canonical declaration ownership, version and export/runtime-binding metadata. No module source or resource URL is delivered. |
| `target.implementation.definitionRevision` | Declared nonempty revision id, or explicit null permitted by the retained canonical declaration. A missing property is refused, never replaced by package version, hash or a fabricated revision. |
| `target.context.subjectId/sessionRevision` | Original in-memory session metadata supplied by the adapter. No session handle, credential, CSRF value or grant is copied. |
| `generation.selection/source` | Source-owner invalidation counters, not saved Page revisions or external authority cursors. A private operation epoch additionally suppresses superseded async results. |

Snapshots and all nested metadata are frozen. Their public types are deeply readonly; identified results have a private, type-only opaque brand, so a normal typed reader consumer cannot construct/promote one from an unavailable result. The reader has no setter, resolver input, success switch or persistence operation. Output is explicitly projected to named metadata fields; unknown context fields are excluded. This is an in-process ownership contract, not protection against arbitrary unsafe code/casts, nor a capability/permission mechanism. Serializing or reconstructing metadata cannot establish authorization.

## Supported baseline and refusal matrix

This increment supports a clean retained application-owned Page, explicit stable Card node in a managed layout wrapper, and one canonical installed Card mapping. Dirty state conservatively refuses target identification while preserving editing/autosave behavior. A stable id originally generated by the editor qualifies only once it is actually present in the matched committed baseline; draft-only/generated candidates do not qualify. Repeated uses of the same canonical Card Definition by distinct stable nodes are not duplicate identity attributes: uniqueness is the selected node, its one reference, and its one Definition/package mapping.

| Condition / transition | Result |
| --- | --- |
| Missing original qualified context | NO_CONTEXT |
| Original Application/owner/Page/subject/session changes | Synchronous invalidation; CONTEXT_CHANGED on reevaluation. This owner does not silently adopt a new context. |
| Root/absent candidate or non-Page editor | NO_SELECTION |
| Absent/manual-index/draft-only candidate in saved baseline | MISSING_NODE; no fallback selection. |
| Unwrapped/manual/non-Card/wrong canonical reference | UNSUPPORTED_NODE |
| Parser ambiguity, malformed markup, duplicate node ids/references, invalid metadata/validation | INVALID_SOURCE with no target. The parser/validator remain shared and unchanged. |
| Missing package / duplicate package or platform Component metadata collision | MISSING_DEFINITION / AMBIGUOUS_DEFINITION |
| Missing/mismatched canonical ownership/version/export/revision evidence | INVALID_DEFINITION |
| Page Shell/modes/form/bindings/events/conditions/repeaters/state/sources/dependencies; nonempty function source beyond exact empty/export {}; unsupported executable/semantic markup or Card mode | UNSUPPORTED_SEMANTICS. No semantic renderer/fallback is introduced. |
| Missing/mismatched committed hash, baseline/files disagreement, uncertain source state | SOURCE_UNCERTAIN |
| Any source edit, insertion/removal/rename, Undo/Redo | Synchronous SOURCE_CHANGED invalidation; explicit evaluation while dirty returns DIRTY_DRAFT. Clean Undo alone does not restore an old target. |
| Selection/navigation | Synchronous SELECTION_CHANGED; explicit candidate may start a new baseline evaluation. Focus without a candidate never republishes cached selection. |
| Save starts | SAVE_PENDING; candidate is not committed evidence. |
| Save failure/conflict | Invalidate; SAVE_FAILED or SOURCE_UNCERTAIN on reevaluation. No recovery/read/save is initiated by target code. |
| Successful save | Reevaluate only after authoritative response, matching retained bundle/baseline/hash, clean current saved generation and unchanged selection/context/operation epoch. Superseded responses do not republish. |
| Known external/workspace event or observed source/dependency/package change | Synchronous invalidation before changing retained state; no automatic cached target restoration. Existing refresh mechanism is reused, not expanded. |
| Park/deactivate/visibility transition | Unavailable; remount/focus alone does not restore a target. |
| Suspension | SUSPENDED; resumed editing still needs explicit valid selection under the original context. |
| Disposal | Terminal DISPOSED before notification; unsubscribe context/visibility, clear metadata listeners and suppress late hash/save callbacks. |

Pending hash evaluation remains unavailable. Only matching-generation completion can publish identified metadata. Observer exceptions do not interrupt edits or saves; reentrant notifications cannot deliver an older identified result after a newer invalidation. Unsubscription and detached subscribe calls are supported.

No current editable draft is supplied to the identity resolver. The existing editor still parses its draft for its ordinary structure/inspector UI. The new source-owner resolver uses only the copied retained committed bundle/baseline, package declaration metadata, platform Component ids (not Component source), original context and selected candidate. Hashing needs an available Web Crypto implementation; unavailable hashing fails closed without a fallback.

No source bytes, markup, locator, credentials, grants, tokens or resource URLs enter the output. No new parser/catalog, polling, reload, save, recovery, native rendering or provider-success response exists.
