## Evidence protocol

Every scenario records repository commits, exact package inputs/runtime target, application/environment and permanent IDs, actor and separately granted capabilities, setup versus user actions, release/hash/schema/policy pins, direct request outcomes, relevant audit correlation, browser observations and preservation/changed-file inventory. Redact credentials. Capture negative results and errors as well as successes. Test doubles/source inspection cannot substitute for actual browser/production boundaries. Existing tests are starting points, not proof they were rerun here.

Each row is **pending new V1 qualification** unless a historical subset is explicitly marked ACCEPTED. A failure of any required criterion fails that row. Missing evidence is UNVERIFIED, not a pass. Environmental refusal is recorded with exact prerequisites. Do not reopen unrelated accepted features to run a broad audit; re-exercise only the affected integration/regression boundary.
