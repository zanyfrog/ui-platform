## Lifecycle implementation

Source changes invalidate before notifications; existing EditingLifecycle subscriptions cover edit/history, saving, conflict/failure, reset and suspension events. Selection/navigation explicitly invalidate; only an explicit candidate triggers a new evaluation. Existing external/workspace notifications invalidate before refreshing/replacing known source state; observed Page/dependency/package changes also invalidate. No polling, reload, save or recovery mechanism was added. Visibility adds only a metadata invalidation listener.

Save initiation invalidates, then the existing source-owner save callback captures the private invalidation epoch, selection generation, original context and editing generation. It awaits the existing captured transport; only an unchanged stamp can nominate completion. Final lifecycle emission must have matching current/saved generation, no in-flight work, no failure and a clean matching baseline before reevaluation. Hash checking is async, but publication is gated again against the captured epoch and complete owned-state signature. Late responses may follow the existing editor's save semantics but cannot restore obsolete metadata. No optimistic candidate is published.

Park/deactivation clears eligibility; remount with cached focus does not republish. Suspension refuses immediately. Disposal becomes terminal before notifying observers, unsubscribes context/visibility and clears metadata listeners. Reentrant disposal and late save/hash callbacks cannot restore a target. Listener exceptions are isolated from editing. Output is deeply frozen and projected to named metadata fields; no source/credentials/capability are exposed.
